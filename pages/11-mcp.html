第十一章 MCP 配置

Model Context Protocol——让 AI 无缝连接外部数据源和工具

11.1 什么是 MCP

MCP（Model Context Protocol，模型上下文协议）旨在解决大语言模型（LLM）与外部数据源及工具之间无缝集成的需求。它通过标准化 AI 系统与数据源的交互方式，帮助模型获取更丰富的上下文信息，从而生成更准确、更相关的响应。

💡 通俗理解

MCP 就像 USB 接口——数据库、Jira、浏览器、地图、API 都能"插"上去，让 AI 直接使用这些工具。

11.2 MCP 核心功能

功能说明
上下文共享应用程序可以通过 MCP 向模型提供所需的上下文信息（如文件内容、数据库记录等），增强模型的理解能力
工具暴露MCP 允许应用程序将功能（如文件读写、API 调用）暴露给模型，模型可以调用这些工具完成复杂任务
可组合的工作流开发者可以利用 MCP 集成多个服务和组件，构建灵活、可扩展的 AI 工作流
安全性通过本地服务器运行，MCP 避免将敏感数据上传至第三方平台，确保数据隐私

11.3 一键安装 MCP Server

WorkBuddy 内置了 MCP Market，提供了大量预配置的 MCP Server，可以一键安装：

  1. 在侧栏对话面板右上方，点击 CodeBuddy Settings 按钮
  2. 切换到 MCP 标签页
  3. 在 MCP Market 中浏览可用的 MCP Server
  4. 根据你的实际需求，选择 MCP Server 进行一键安装
  5. 安装成功后，MCP Server 显示绿色状态；安装失败显示红色状态
💡 状态说明

绿色 = 安装成功，正在运行 ｜ 红色 = 安装失败，需排查

11.4 自定义配置 MCP Server

如果 MCP Market 中没有你需要的 Server，可以手动配置：

  1. 在 MCP 标签页下，点击右侧 Add MCP 按钮
  2. 在 JSON 配置文件中，添加 MCP Server 配置内容
  3. 保存配置

配置示例

{
  "mcpServers": {
    "python-tools": {
      "type": "stdio",
      "command": "python",
      "args": ["-m", "my_mcp_server"],
      "env": {
        "PYTHONPATH": "/path/to/tools"
      },
      "description": "Python 工具集"
    }
  }
}

配置文件位置

级别路径作用范围
用户级~/.workbuddy/mcp.json所有项目共享
项目级项目工作目录下的配置仅当前项目

配置字段说明

字段说明
type通信类型，常用 stdio（标准输入输出）
command启动 MCP Server 的命令
args命令参数数组
env环境变量
descriptionServer 描述信息

企业微信机器人 WebHook 接入示例

{
  "mcpServers": {
    "wecom-bot": {
      "type": "stdio",
      "command": "node",
      "args": ["-m", "wecom-bot-mcp"],
      "env": {
        "WEBHOOK_URL": "https://qyapi.weixin.qq.com/cgi-bin/webhook/send?key=YOUR_KEY"
      },
      "description": "企业微信机器人消息推送"
    }
  }
}

11.5 使用 MCP

MCP Server 安装成功后，你有两种方式使用：

方式一：验证使用

在 MCP Server 右侧点击 Try to Run 按钮，进行验证和测试。

方式二：任务中调用

直接在 Craft 模式下输入任务需求，Agent 会根据你的任务需求进行分析，然后自动调用 MCP Server 工具来完成任务。

💡 使用示例

配置了数据库 MCP 后，你可以说："查询数据库里上周的销售记录，生成一份分析报告"——WorkBuddy 会自动调用 MCP 工具查询数据库，然后生成报告。

⚠️ 安全提醒

自定义 MCP Server 的访问范围由你的配置决定，WorkBuddy 不预设范围，请审慎评估后再启用。API 密钥与 Token 请妥善保管，避免在公共设备或共享环境填写。
