第二章 安装与配置

从零开始：下载安装、账号登录、界面认识与初始配置

2.1 环境准备

系统要求

操作系统最低版本备注
WindowsWindows 10 (1903+)建议 Windows 11
macOSmacOS 11 (Big Sur)+支持 Intel 和 Apple Silicon

必备运行环境

⚠️ 安装前必读

请确保已安装以下运行环境，并在安装后重启电脑：

  • Node.js（v18+）：用于技能和 MCP 脚本运行
  • Git：用于版本管理和代码相关任务
  • .NET Runtime（仅 Windows）：部分功能依赖
💡 安装建议

安装 WorkBuddy 前建议关闭杀毒软件和同类 AI 工具，避免安装被拦截或冲突。安装路径避免使用中文。

2.2 下载与安装

Windows 安装

  1. 访问官网 codebuddy.cn，点击下载 Windows 版安装包（约 487MB）
  2. 右键 → 以管理员身份运行 Setup.exe
  3. 选择安装路径（建议默认路径，避免中文和空格）
  4. 等待安装完成，点击"完成"启动 WorkBuddy
  5. 重启电脑（确保运行环境生效）

macOS 安装

  1. 访问官网下载 macOS 版安装包（.dmg 文件）
  2. 双击打开 .dmg 文件
  3. 将 WorkBuddy 图标拖拽至"应用程序"文件夹
  4. 首次打开时如提示"无法验证开发者"，前往"系统偏好设置 → 安全性与隐私"，点击"仍要打开"
  5. 启动 WorkBuddy

2.5 初始配置

文件夹授权

首次使用需要授权 WorkBuddy 访问本地文件夹：

  1. 点击"选择工作空间"或前往设置页面
  2. 勾选需要授权的文件夹（推荐：桌面、文档、下载）
  3. 系统敏感目录会自动拦截，无需担心
  4. 高危操作（删除、移动）需要二次确认
🔒 安全提示

WorkBuddy 只能访问你主动勾选授权的文件夹。所有文件处理默认在本地完成，原始数据不上传云端。服务端仅处理数据片段，用后即弃，不保存也不用于模型训练。
