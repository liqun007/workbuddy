第八章 技能系统 Skills

技能是 WorkBuddy 的"超能力插件"——安装即用，无限扩展

8.1 什么是技能

技能（Skill）是可复用的 WorkBuddy 能力扩展单元，封装了特定领域的指令、工具和知识，使智能体能够执行专业化的任务。

你可以把它理解为给 AI 同事安装的"专业培训"。每个技能封装了一套针对特定场景的专业工作流。

📊 技能生态数据
  • SkillHub 已收录 7 万+ 技能
  • 上线两月累计下载 3000 万+
  • 覆盖文档处理、数据分析、代码开发、设计创意等多个领域
  • 内置技能 301 个，无需安装即可使用
特征说明
可发现性成员可在客户端按分类浏览和使用已安装的 Skill
可管控性管理员可控制每个 Skill 的可见范围和使用权限
可扩展性支持企业统一下发和成员自定义两种来源

8.2 技能市场

技能市场分为已安装区和推荐区：

区域说明
已安装区展示你已经安装的技能，可以启用/禁用/卸载
推荐区展示技能市场推荐的热门技能，可以一键安装

你可以在技能市场中：

  • 按分类浏览技能
  • 搜索特定技能（如"Excel 自动化"、"会议纪要"）
  • 一键安装或上传导入
  • 在对话中输入 / 快速唤起技能列表

8.3 安装与使用技能

安装技能

  1. 在左侧菜单栏点击 "技能"，浏览技能市场
  2. 搜索你需要的技能（如"Excel 自动化"、"会议纪要"）
  3. 点击技能卡片查看详情
  4. 点击 "安装"，一键完成
  5. 安装后即可在对话中调用

使用技能

  1. 在对话输入框中输入 / 快速唤起技能列表
  2. 选择需要的技能
  3. 按照技能提示输入任务描述
  4. WorkBuddy 自动调用技能能力执行任务
💡 快捷调用

在输入框输入 / 可以快速唤起已安装的技能列表，无需每次去技能市场查找。

8.5 创建自定义技能

除了使用市场中的技能，你还可以创建自己的自定义技能（零代码）：

技能包结构

my-skill/
├── SKILL.md          # [必填] 名称 + 描述 + 使用说明
├── manifest.yaml      # [必填] 版本、依赖、元数据
├── scripts/           # [可选] 可执行脚本
├── references/        # [可选] 参考文档
└── assets/            # [可选] 图标、模板等资源

manifest.yaml 最小示例

name: my-skill
version: 1.0.0
description: "我的自定义技能"
category: data-processing
author: my-name

创建步骤

  1. 按照上述结构创建技能包文件夹
  2. 编写 SKILL.md，描述技能功能和使用方式
  3. 编写 manifest.yaml，声明版本和依赖
  4. （可选）编写脚本和参考文档
  5. 在技能市场中上传导入

8.6 技能管理

技能分类

技能按业务领域分组，客户端以树形结构呈现。管理员可创建分类、设置排序位置。

下发策略

策略类型定义适用场景
白名单策略指定成员仅能使用列表中的技能新员工入职、外包人员受限
黑名单策略禁止指定成员使用列表中的技能高风险技能限制、敏感操作限定
默认允许无策略时默认允许使用无特殊限制的场景
⚠️ 优先级规则

黑名单 > 白名单 > 默认允许。"下发策略"与"客户端上传策略"相互独立。
