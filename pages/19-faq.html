19.1 高频问题解答

Q1: WorkBuddy 无法启动？

可能原因：缺少运行环境、杀毒软件拦截、安装路径含中文。

解决方案：

  • 确保已安装 Node.js、Git、.NET（Windows）并重启电脑
  • 关闭杀毒软件后重新安装
  • 重新安装到无中文的路径

Q2: 插件/技能安装失败？

可能原因：缺少运行环境依赖、网络问题。

解决方案：检查 Node.js 版本是否满足要求 → 检查网络连接 → 尝试重新安装。

Q3: 指令执行失败？

可能原因：文件路径错误、权限不足、文件格式不支持。

解决方案：确认文件路径正确 → 检查文件夹授权 → 确认文件格式受支持。

Q4: macOS 提示"无法打开"？

解决方案：前往"系统偏好设置 → 安全性与隐私"，点击"仍要打开"授权。

Q5: Credits 不足怎么办？

解决方案：

  • 新用户注册即送 5000 Credits
  • 基础版 19 元/月
  • 选用混元模型可节省消耗
  • 避免重复任务，善用继续对话

Q6: 端口被占用？

解决方案：检查是否有其他 WorkBuddy 实例在运行 → 关闭占用端口的程序 → 重启 WorkBuddy。

Q7: 上传文件失败？

解决方案：检查文件格式是否受支持 → 大文件可先压缩拆分 → 检查网络连接。

Q8: 远程操控无响应？

解决方案：检查电脑是否开机且 WorkBuddy 在线 → 检查网络连接 → 重新绑定 IM 渠道。

Q9: WorkBuddy 和 ChatGPT/Claude 有什么区别？

WorkBuddy 不是聊天工具，而是数字劳动力——它能实际执行任务、操作本地文件、交付成果（文档/表格/PPT），而不仅仅输出文字。此外还支持多端远程操控、连接器生态、自动化定时任务等。

Q10: 数据安全吗？

安全。所有文件处理默认在本地完成，原始数据不上传云端。服务端仅处理数据片段，用后即弃，不保存也不用于模型训练。只能访问你主动授权的文件夹，系统敏感目录自动拦截，高危操作需二次确认。

19.2 避坑提醒

🚫 七大避坑提醒
  1. 拒第三方下载：仅从官网 codebuddy.cn 下载，避免安全风险
  2. 谨慎授权：只授权必要文件夹，不授权整个磁盘
  3. 重视计划：复杂任务用 Plan 模式，先看计划再执行
  4. 装后重启：安装完成后务必重启电脑，确保环境生效
  5. 关杀软：安装时关闭杀毒软件，避免被拦截
  6. 避中文路径：安装路径避免中文，防止兼容问题
  7. 常备份：重要文件先备份再修改，养成习惯
