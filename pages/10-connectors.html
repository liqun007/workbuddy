第十章 连接器 Connectors

连接外部服务的桥梁——让 AI 直接读写第三方平台数据

10.1 什么是连接器

连接器用于将 WorkBuddy 与外部服务进行对接，实现数据互通与能力扩展。通过配置连接器，你可以让 WorkBuddy 直接访问和操作第三方服务。

连接器是 WorkBuddy 与外部服务之间的桥梁，将外部能力引入 AI 工作流。技术形态分为：

  • MCP + CLI（标准化协议）
  • Skill + CLI（内置脚本）
🔌 已支持的连接器

QQ 邮箱、腾讯文档、腾讯乐享、TAPD、腾讯网盘，并支持自定义连接器接入 Notion、飞书、钉钉、GitHub 等 30+ 服务。

10.3 连接 QQ 邮箱

QQ 邮箱连接器支持收发、搜索和整理 QQ 邮件，用自然语言读取邮件内容、汇总邮件线程、管理文件夹。

  1. 点击添加：在连接器管理页面找到"QQ 邮箱"卡片，点击右侧 + 按钮
  2. 扫码授权：系统跳转到 QQ 邮箱授权页面，显示二维码。使用 QQ 邮箱 App（7.1.5 / 鸿蒙 0.2.9 及更新版本）扫码
  3. 确认权限：在手机端确认 WorkBuddy 申请的访问权限（账号信息、读取邮件、发送邮件、删除邮件）
  4. 授权成功：手机端显示授权成功。点击浏览器弹窗中的"打开"完成连接
  5. 连接完成：回到 WorkBuddy，QQ 邮箱卡片名称旁出现绿色圆点
⚠️ 注意

授权成功时点击浏览器弹窗中的 "打开" 完成连接。取消或关闭网页可能导致操作中断，需要重新配置。

QQ 邮箱连接器功能

  • 收取阅读邮件
  • 搜索提取邮件内容
  • 摘要提炼邮件线程
  • 起草发送邮件
  • 分类归档邮件
  • 自动化工作流（定时收取邮件摘要）
  • 离线处理（EML/MBOX/PST 文件）
  • 审批联动

10.4 连接腾讯文档

腾讯文档连接器支持直接读写云端文档，实现"语义搜索 → 处理 → 一键回存"的三步闭环。

  1. 在连接器管理页面找到"腾讯文档"卡片，点击 + 按钮
  2. 跳转到腾讯文档授权页面
  3. 确认 WorkBuddy 将获取的权限
  4. 点击"同意授权"
  5. 回到 WorkBuddy，连接完成

实战示例

  • 报告摘要：指令"读取腾讯文档里的项目报告，生成 300 字摘要"
  • PPT 大纲：指令"从腾讯文档的需求文档提取要点，生成 PPT 大纲"
  • 周报闭环：指令"读取本周各项目文档，汇总生成周报并回存到腾讯文档"

10.5 连接腾讯乐享

腾讯乐享连接器支持搜索、创建和管理乐享知识库中的文档，支持导入 Markdown、按标签整理内容、追踪团队文档更新动态。

  1. 在连接器管理页面找到"腾讯乐享"卡片，点击 + 按钮
  2. 进入授权确认页面，点击"立即前往授权"
  3. 系统跳转到腾讯乐享登录页面（支持微信登录、手机号登录）
  4. 页面显示账号信息和权限列表，点击"继续"
  5. 回到 WorkBuddy，连接完成

10.6 自定义连接器

如需接入其他外部服务，可点击连接器管理页面右上角的"自定义连接器"按钮，安装自定义的 MCP 服务。

10.7 管理与安全

连接器管理

  • 点击连接器卡片右侧开关即可启用/禁用
  • 点击开关确认"断开"可断开连接
  • 断开后可随时重新连接

权限边界

  • 每个连接器独立授权
  • 不主动定时抓取，仅在指令触发时按需读取
  • 不超出你已有权限范围

安全提示

🔒 安全注意事项
  • 连接器需相应服务的访问权限，请确保授权信息正确
  • 授权后可随时通过开关禁用或断开连接器
  • QQ 邮箱授权撤销：QQ 邮箱 App → 设置 → 账号 → 安全管理 → 应用授权
  • API 密钥与 Token 是访问第三方账号的钥匙，请妥善保管
  • 不再使用的连接器建议及时撤销授权
  • 建议定期检查连接器状态
💰 积分消耗

连接器自身的读写不消耗积分；WorkBuddy 对外部数据进行理解、汇总时会消耗积分。
