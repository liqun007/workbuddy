第十三章 记忆系统 Memory

让 WorkBuddy 记住你的偏好和习惯——对话越多，它就越懂你

13.1 什么是记忆

记忆功能从你的会话历史中提取具有参考价值的个人信息（事实信息、偏好习惯、人物关系、近期跟进事项等）形成「记忆数据」并定期更新。后续对话或任务执行时，会将与当前请求相关的记忆作为背景信息一并参考。

💡 核心特点
  • 提取频率：每晚整理当天会话，仅你本人可见
  • 编辑记忆：可从头像处进入「设置 - 记忆」中查看、编辑、删除或一键关闭
  • 记忆功能不消耗积分：记忆提取由 WorkBuddy 自费完成

13.2 记忆类型

WorkBuddy 的记忆系统分为三个层级，各有不同的作用范围和写入策略：

层级存储位置作用范围说明
云端记忆服务器端所有项目自动生成的用户画像摘要，会话开始时注入。支持历史对话检索（如"上周做过什么"）
用户级本地记忆~/.workbuddy/MEMORY.md所有项目手动写入的长期规则和偏好，限制 4000 字符/会话
工作区记忆项目 .workbuddy/memory/当前项目项目专属记忆，含每日日志和长期笔记

记忆数据类型

类型示例
事实信息"用户是 Python 开发者"、"使用 macOS"
偏好习惯"报告偏好蓝色风格 16pt"、"代码用 4 空格缩进"
人物关系"张三是团队 Leader"、"李四是产品经理"
跟进事项"上周在处理 XX 项目的 API 重构"

13.3 管理记忆

生成对话记忆

默认开启，允许 WorkBuddy 从对话中提取并记住相关上下文，以便在未来对话中提供更连贯、个性化的回应。

查看记忆

记忆摘要每晚重新生成。打开已生成的记忆，可查看记忆内容。

编辑记忆

点击右上角编辑图标，唤起对话框通过对话的方式告诉 WorkBuddy 要记住或忘记什么。

💡 主动写入记忆

在对话中说 "记住：XXX" 即可写入记忆配置。例如："记住：我的报告都用蓝色风格、16pt 字体"，长期生效。

删除记忆

点击右上角删除图标，可以清空当前记忆。

一键关闭

在「设置 → 记忆」中可以一键关闭记忆功能，关闭后将停止提取新的记忆。

13.4 导入记忆

支持同步你在其他 AI 上的使用习惯：

  1. 在「设置 → 记忆」中点击 "开始导入"
  2. 复制示例提示词到其他 AI 产品的对话中
  3. 将结果粘贴到 WorkBuddy 的导入框中
  4. 点击 "添加到记忆" 完成导入
💡 跨 AI 迁移

这个功能让你可以从 ChatGPT、Claude 等 AI 产品迁移你的偏好和习惯，无需重新"训练" WorkBuddy。

13.5 隐私与安全

🔒 隐私提醒
  • 记忆内容遵循 WorkBuddy 隐私政策，仅你本人可见
  • 会话中如涉及他人个人信息，请在提交前确认已获得相关授权
  • 记忆功能不涉及第三方共享：记忆数据仅用于产品内部为你本人提供个性化服务

使用建议

  • 记忆由模型基于会话内容自动抽取，可能存在概括偏差或时效性问题，在依赖记忆做重要判断前建议先核验
  • 若不希望某些信息被记住，可在「设置 → 记忆」中删除对应条目或一键关闭功能
  • 关闭或删除记忆条目后，相应数据将停止用于后续对话，但已生成的输出不会因此追溯撤回
