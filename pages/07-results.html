第七章 结果查看

在右侧结果区查看产物、文件、变更和预览

7.1 右侧结果区

任务执行过程中，右侧会显示结果区，用来查看 WorkBuddy 产出的文件、代码变更和内置浏览器预览的内容。你不需要离开当前任务，就可以一边看对话，一边查看结果。

当前结果区主要提供四类内容：

视图说明
概览工作空间文件、浏览器、变更
产物查看任务生成的文件和交付物

7.2 产物管理

当任务生成文件、表格、文档或其他可交付内容时，你可以在产物中统一查看和分享。

适合在产物中查看的内容

  • 文档类结果（Word、Markdown、PDF 等）
  • 表格类结果（Excel、CSV 等）
  • 演示文稿（PPT）
  • 分析报告
  • 自动生成的交付文件

7.3 网页预览

如果任务生成的是网页、页面原型或本地启动的 Web 应用，你可以在内置浏览器中直接查看效果。

内置浏览器通常会提供：

  • 当前页面地址
  • 刷新入口
  • 页面内容的实时查看
💡 适用场景

适合用于确认页面结构、样式和交互结果是否符合预期。开发网站或 Web 应用时尤其有用。

7.4 工作空间文件

工作空间文件用于查看当前工作空间中的文件内容，适合在不离开任务的情况下直接浏览产出文件。

这一视图通常包含：

  • 左侧文件列表或文件树
  • 右侧文件内容区域
  • 顶部已打开文件的切换栏

适合用来：

  • 快速查看某个生成文件的完整内容
  • 对照不同文件之间的关系
  • 检查任务是否写入了正确的位置

7.5 变更视图

变更视图用于查看当前任务带来的文件修改，方便你在接受结果前先做一轮检查。

这一视图通常会显示：

  • 本次修改涉及的文件列表
  • 每个文件的改动情况
  • 选中文件后的具体变更内容
⚠️ 建议先检查

如果任务涉及代码开发、脚本生成或配置调整，建议优先在变更视图中确认改动是否符合预期，再接受结果。

7.6 产物分享与上传

产物分享

在预览产物文件时，点击右上角分享图标，可以生成分享链接。

上传到云端

支持上传到以下平台，在其他端的应用内也可以查看：

平台说明
📁 我的云端网盘腾讯网盘，个人云存储
📄 腾讯文档在线文档平台
📚 ima 知识库ima 知识管理平台
📖 乐享知识库腾讯乐享，企业知识库
✅ 完整闭环

从"生成产物 → 预览确认 → 上传云端 → 分享他人"，WorkBuddy 提供了完整的工作闭环。
