第三章 三大工作模式

Ask、Plan、Craft 三种模式详解——什么时候该用哪种

WorkBuddy 提供三种工作模式，适应不同的任务场景和风险控制需求。理解它们的区别是高效使用 WorkBuddy 的关键。

3.1 Ask 问答模式

💬 Ask = 只回答，不动手

适用于咨询、解读、知识问答。WorkBuddy 只输出文字回复，不操作任何文件。

适用场景

  • 概念解释："什么是 MCP 协议？"
  • 方案咨询："Excel 数据透视表和普通表格有什么区别？"
  • 代码解读："解释一下这段代码的作用"
  • 写作建议："帮我想几个周报的开头"

使用方法

  1. 在输入框选择 Ask 模式
  2. 直接输入你的问题
  3. 按回车或点击发送
  4. 查看文字回复，可继续追问
✅ 零风险

Ask 模式不操作任何文件，完全安全，适合初次体验和快速咨询。

3.2 Plan 规划模式

📋 Plan = 先规划，确认后执行

适用于多步骤复杂任务。WorkBuddy 先分析需求、制定计划，等你确认后再执行。

工作流程

  1. 指令：你描述任务需求
  2. 规划：WorkBuddy 分析需求并生成执行计划
  3. 确认：你审查计划，可修改或确认
  4. 执行：WorkBuddy 按计划逐步执行
  5. 交付：输出可验收的成果

适用场景

  • 代码重构："把这个项目的认证模块重构为 JWT 方案"
  • 架构设计："设计一个电商微服务架构方案"
  • 复杂文档："生成一份完整的技术方案文档，包含架构图、API 设计、数据库设计"
  • 数据分析："分析这份销售数据，找出增长趋势和异常点"
⚠️ 风险可控

Plan 模式在执行前需要你确认计划，适合涉及重要文件或不可逆操作的场景。建议在执行复杂任务前优先使用。

3.3 Craft 执行模式

⚡ Craft = 理解即执行

适用于日常快速任务。WorkBuddy 理解需求后直接执行并交付成果。

适用场景

  • 文档生成："生成一份本周工作周报"
  • 数据处理："帮我把这份 Excel 数据清洗去重，生成透视表"
  • PPT 制作："根据这份大纲生成一个产品介绍 PPT"
  • 批量处理："把文件夹里所有 PNG 图片转为 JPG"
  • 文件整理："整理下载文件夹，按文件类型分类"
💡 使用建议

Craft 模式效率最高，适合明确的日常任务。涉及重要文件时，可以先备份再使用。

3.4 模式对比与选择

维度AskPlanCraft
执行方式只问答，不动文件先规划，确认后执行理解即执行
输出形态文字回复计划 + 成果交付成果文件
风险等级零风险可控（确认后执行）低风险（直接执行）
适用任务咨询、解读重构、架构设计数据清洗、文档生成
推荐场景初次体验重要/复杂任务日常快速任务
🎯 选择建议
  • 不确定用哪个？ 先用 Ask 问清楚，再用 Craft 执行
  • 任务复杂且重要？ 用 Plan，先看计划再执行
  • 日常简单任务？ 直接用 Craft，效率最高
  • 只是想咨询？ 用 Ask，零风险
💡 上手路径建议

新手推荐路径：Ask 熟悉 → Craft 简单任务 → Plan 复杂任务 → 装技能连连接器 → 自动化
